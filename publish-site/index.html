v1.2 社区版 新功能：
· 自研 10yv 核心：内置完全自研的 Rainclouds 10yv 核心引擎（对标 Fabric），提供自有 Mod API 与事件总线，自带 3 个演示 Mod（hello / fps / spawninfo）。
· Mod 与插件共存：每个档案独立游戏目录，Fabric/Forge Mod 与 Bukkit/Spigot/Paper 插件按实例隔离，自研 Mod 使用 rainclouds.mod.json 清单互不冲突。
· 进阶模块（¥20 打包解锁）：联机、内网穿透（内置 frpc，自备服务器）、一键开服（原版 / Paper / Fabric）三大模块一次解锁全部。
· 启动页面：启动先显示 Rainclouds 启动页，再进入主窗口。
· 数字签名：rcl.exe 已用 Rainclouds 自签名证书签名，属性版权栏显示 Copyright © Rainclouds。
使用提示：
· 首次使用建议在「设置」中填入你自己的微软 Azure 应用 ClientId（见 README）。
· 内置默认 ClientId 可直接试用，但稳定性以自建应用为佳。
